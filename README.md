# LX Music 移动版 · 个人修改版

> 基于 [LX Music 移动版 v1.9.2](https://github.com/lyswhut/lx-music-mobile) 的个人学习用途修改版。
> **本项目仅用于技术学习与交流，不提供任何音源，使用须遵守原项目协议（Apache-2.0）。**

## 关于本项目

在原版基础上做了一些交互上的调整，目的只是练习 React Native 开发与阅读大型开源项目。
**不提供、不内置、不推荐任何音乐接口**，播放功能需要自行配置音源，与原项目的要求一致。

- 上游项目：<https://github.com/lyswhut/lx-music-mobile>
- 上游使用文档：<https://lyswhut.github.io/lx-music-doc/mobile/>
- 上游 README 备份见 [README.upstream.md](./README.upstream.md)

## 本版改动

### 1. 列表点歌 → 播放整个列表

点击列表里的任意一首歌，会把**当前整个列表**设为播放队列，并从点击的那首开始播放。
（原版只在列表为空时才这样处理）

### 2. 播放队列按钮 + 队列面板

- 主播放条、播放详情页都新增了**队列按钮**（图标跟随主题色）
- 点击弹出底部队列面板：显示队列名称、歌曲数量
- 面板里当前播放的歌曲用**主题色高亮**（底色 + 左侧竖条），点歌曲直接切歌

### 3. 播放详情页按钮布局

- 按钮顺序：**上一首 → 播放/暂停 → 下一首**
- **队列按钮固定在控制行的最右侧**（绝对定位），竖屏、横屏一致
- 补齐了之前缺失的「上一首」按钮

### 4. 在线列表当前播放歌曲高亮

排行榜、歌单、搜索结果等在线列表里，正在播放的歌曲会：
- 背景使用主题色半透明底
- 左侧出现 3px 主题色竖条
- 歌曲名变成主题色，序号变成播放图标

### 5. 右下角「定位当前播放」

所有歌曲列表右下角都有悬浮定位按钮，点一下**滚动到正在播放的歌曲**。

### 6. 歌曲统一带专辑封面

所有出现歌曲的地方统一显示专辑封面：

| 位置 | 封面尺寸 | 行高 |
| --- | --- | --- |
| 在线列表（排行榜 / 歌单 / 搜索） | 54 | 64 |
| 我的列表 | 54 | 64 |
| 播放队列面板 | 50 | 68 |

封面统一 5px 圆角，序号列相应收窄给封面让位。
没有封面的本地歌曲会显示项目自带的占位图。
